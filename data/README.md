# Data

The raw market datasets used in this project were downloaded manually from **Investing.com** and are not redistributed in this repository.

To reproduce the analysis, place the required CSV files in this directory using the following filenames:

- `Gold Futures.csv`
- `Crude Oil WTI.csv`
- `S&P 500.csv`
- `Bitcoin.csv`
- `USD_JPY.csv`
- `US Dollar Index.csv`

The notebook automatically uses this `data/` directory when the corresponding Google Drive directory is not available.

Users reproducing the project should obtain equivalent historical market data directly from the original data provider.
